# 积分结算规则（用户协议草案，需法务确认）

本文描述系统已经自动执行的规则，供写入用户协议和价格页。条款措辞需法务确认；规则改动时须同步修改代码和测试（`tests/test_api.py`、`tests/test_billing.py`）。

## 积分

- 积分通过购买积分包、兑换码或平台赠送获得。购买的积分不过期；赠送和兑换码积分可以设有效期，到期后未使用的部分失效。
- 使用时先扣即将过期的积分。已冻结的积分不会因过期被扣除。
- 积分余额和每一笔变动可在“积分”页查看。

## 下单与冻结

- 下单前显示分阶段估价。确认下单时按页数上限冻结估价金额；冻结的积分不能用于其他任务。
- 页面上的价格为测试期价格，正式价格以下单时显示的估价为准。

## 结算

- 每个阶段完成后结算该阶段的积分：规划（基础费）、母版（按页）、原生重建（按页）、打包和附加项。
- 实际页数少于冻结所用的上限时，未用完的冻结积分在交付时释放；实际费用超出估价的部分由平台承担。
- 母版单页重做、超出免费轮次的返修，在提交前显示扣费金额，确认后从可用积分中扣除。

## 取消、失败与暂停

- 用户取消：已完成阶段按上述规则结算，其余冻结积分立即释放。
- 系统失败（平台原因导致任务无法完成）：已完成阶段保留结算，未完成部分的冻结积分自动释放；可重试的故障会自动重试，不另外收费。
- 暂停（缺少用户才能提供的资料或确认）：冻结保持不变，用户处理后继续；用户也可以选择取消。
- 账号用量上限等平台侧原因造成的延迟不收取额外费用。

## 退款

- 购买的积分包可申请退款：只退该订单中尚未使用、未冻结的积分，按该订单的单价折算金额原路退回。
- 赠送、兑换码积分不可退款。

## 交付与验收

- 原生可编辑版需要用户在预览中写下接受的范围并批准；批准原话记入验收记录。
- 平台不承诺原生可编辑版与母版逐像素一致；内容准确性由用户最终负责。
