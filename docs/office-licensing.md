# Office 授权与 Worker 机器成本评估（P0）

编写 2026-10-19（Claude）。基于微软公开的授权与支持说明的通行理解，**不是法律意见**；采购前请向微软或经销商确认最新条款和价格。

## 1. 为什么需要 Office

原生可编辑版和矢量化的验收靠 PowerPoint 渲染（真实打开、逐页导出、与母版对比），以及矢量化时把用户 PPTX 渲染成页面图。
规划包和图片版不需要 Office（图片版打包用 python-pptx）。

## 2. 微软的立场

- 微软长期声明**不推荐、也不支持**在无人值守的服务器进程里自动化 Office（“Considerations for server-side Automation of Office”）。
  技术上可行（本项目已在桌面会话里用 COM 稳定跑通，并有看门狗、单机单任务的 Office 锁），但出问题时得不到官方支持。
- 授权方面，Microsoft 365 / Office 是**按用户**授权的桌面软件。让服务器替大量外部用户运行 Office、把结果交付给他们，
  是否被许可需要和微软确认；常见做法是给运行 Worker 的专用账号购买一份 Microsoft 365 Apps 商业版许可，并在多会话或服务器系统上
  使用时确认“共享计算机激活”的条件。

## 3. 选项

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| A. 专用 Windows 机器 + Microsoft 365 Apps 商业版（每台一个 Worker 账号） | 与当前实测环境一致；渲染最可靠 | 需确认对外服务的授权；按机器扩容 |
| B. 云上 Windows 虚拟机（每台一个 Office 任务） | 可快照还原、按需扩容 | 云厂商的 Windows 授权费另计；GPU/桌面会话配置 |
| C. 只在内测期用 Office，对外先只开规划包和图片版 | 零 Office 授权问题 | 原生可编辑版要等方案确定 |
| D. 替代渲染器（LibreOffice 等） | 无微软授权问题 | 与 PowerPoint 渲染有差异，验收标准（v66）基于 PowerPoint，不能直接替代 |

## 4. 成本粗算（用实测数据）

- 实测 PowerPoint 渲染每次 7–19 s；一份 9 页原生版全流程 Office 占用约 76 s（`J-plan-real-001`）。瓶颈不在 Office，在代理会话
  （原生重建约 3.7 小时代理时间）。
- 一台 Worker 机器同一时间只跑一个 Office 任务；按每单原生重建 1–4 小时估，一台机器每天约 6–20 单原生版。
- 每台机器的固定成本 = 硬件或云主机月费 + Windows 授权 + Microsoft 365 Apps 月费（以采购报价为准）。

## 5. 建议

内测期继续方案 A（现有机器、一个 Worker 账号、一份商业版许可），对外首发按 D6 只开放规划包和图片版（方案 C），
原生可编辑版在授权确认、成本数据充足后再上。系统已支持按能力分派阶段（`office` 能力），没有 Office 的机器也能跑规划和母版。
